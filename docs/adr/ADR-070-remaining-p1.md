# ADR-070 — Finish the remaining P1 paths

Status: Adopted. This is the current English summary of the decision. The original implementation log remains available in Git history.

## Decision and current interpretation

The Windows `m8-finish` pass completed the remaining P1 work recorded in the earlier plan: agent defaults, accessibility and keyboard work, import recovery, object image operations, outline editing, font settings, and other editor controls. It also fixed a Windows case-collision in filenames and added a regression check. The original record distinguishes implemented capability from parts needing a configured model or manual accessibility review. Later design refresh and unified import chat change some UI placement; see the current PLAN and [ADR-077](ADR-077-import-conversation.md).
